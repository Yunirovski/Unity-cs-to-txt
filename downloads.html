下载你文件夹里的文件

这个页面是单独的新页面，专门负责下载你网站目录里的文件。你把文件放进同一个项目里的 files 文件夹，然后把链接改成对应文件名，就能直接下载。

下面默认按 ./files/文件名 的方式写好了。假设你的项目结构是 index.html 和 downloads.html 在根目录，下载文件都放在 files 文件夹里。

你的目录该怎么放

  1. 在项目根目录新建一个 files 文件夹。
  2. 把你要下载的文件放进去，比如 files/index.html。
  3. 把这个页面保存成 downloads.html。
  4. 从主站加一个按钮跳转到 downloads.html。
Unity-cs-to-txt/ ├─ index.html ├─ downloads.html └─ files/ ├─ index.html ├─ 1.zip └─ 1.txt

如果你其实是想下载当前项目根目录里的文件，而不是 files 子文件夹，我也可以帮你改成直接下载根目录文件的版本。

你现在只要把文件丢进 files 文件夹，再把文件名改成真实名称，就能用了。
